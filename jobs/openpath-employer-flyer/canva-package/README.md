# OpenPath Employer Flyer — Canva package

**Includes FOR EMPLOYERS** in the header.

Canva does **not** use a downloadable `.canva` file on disk. Designs live in your Canva account. This package gets you an editable Canva design two ways.

## Fastest: import the PDF into Canva

1. Open: https://www.canva.com/pdf-editor/
2. Upload: `OpenPath-Employer-Flyer-FOR-CANVA.pdf`  
   (also in your Downloads folder)
3. Canva opens it as a design and breaks apart text/images where it can.
4. File → make sure size is **8.5 × 11 in** (Letter). Adjust if Canva defaulted to A4.
5. Rename the design: **OpenPath Employer Flyer**.

**Assets for re-upload / replacement if import flattens something:**
- `OpenPath-Logo-horizontal.JPG` — logo (OpenPath Placement Agency)
- `hero-pexels-5439468-hires.jpg` — hero photo (licensed Pexels)
- `qr-employer-contact.png` — QR → openpathplacementagency.com

## Cleaner rebuild (fully editable layers)

Create design → **Custom size** → **8.5 × 11 in** portrait → upload the three assets above → follow `CANVA-LAYERS.md`.

## Native Canva design from Cursor (edit URL)

That needs **Canva Design MCP** connected in Cursor (`https://mcp.canva.com/mcp`). It is not connected in this session, so no live Canva edit link can be generated yet. After you connect and authenticate it, ask again and a real Canva design + edit URL can be created.
